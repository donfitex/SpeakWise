# Learner guide

1. Open My account and create your own account with a strong password. The pilot is for learners aged 16+. It uses fictional sample lessons and advisory feedback.
2. Choose a goal, preferred starting level, daily practice time, and optional pronunciation target. A short text placement suggests a starting level; it is low confidence and does not measure listening or pronunciation. You can override it.
3. Open Classroom and start a lesson. Read the objective and explanation, then the model caption. Listen if a permitted browser voice is available. You can choose a slower speed or remain entirely text-based.
4. Answer one activity at a time. Use a hint, read feedback, and retry. A controlled reference match may reject other valid wording: report feedback for review when needed. It is not a judgment of your accent or intelligence.
5. Speaking practice is optional. After consent, record up to 30 seconds, preview, discard, or submit. No camera is needed. If permission/device/provider support is unavailable, type instead. The default server speech provider is disabled and returns a safe fallback. The operator can enable free offline recognition; its approximate transcript needs review and never produces pronunciation scores.
6. Leave and resume from the course map or dashboard. Completed lessons can be practised again. Progress shows recent controlled-task evidence and due reviews, with reasons; there is no overall mastery score.
7. In My account, withdraw audio consent, download active data, or delete your account with password confirmation. Individual speech results can be deleted in the classroom. Password reset requires the operator's functioning email transport; local development uses an in-memory mailer.

Audio/visual cues are pilot aids awaiting educator review. Child accounts, exam certification, live group calls, complete level coverage, and precise pronunciation grading are not available. See privacy.md for retention and data controls.
